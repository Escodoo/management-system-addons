# Description

This module provides a DMN (Decision Model and Notation) modeler integrated into Odoo,
leveraging the `dmn-js` JavaScript library and Odoo's OWL framework. It allows users to
create, view, and edit DMN decision tables directly within Odoo records.

## Key Features

*   **Interactive DMN Modeling**: Utilize the powerful `dmn-js` library for creating
    and editing DMN decision tables.
*   **Odoo Integration**: Seamlessly embed the DMN modeler into Odoo forms using a
    custom field widget built with OWL.
*   **Decision Table Storage**: Store DMN XML definitions directly within Odoo records.
*   **Version History**: Automatic tracking of decision table versions with change history.
*   **Templates**: Pre-built decision table templates for common business scenarios.
*   **Export/Import**: Export decision tables as XML, SVG, PNG, or PDF, and import
    existing DMN files.
*   **State Management**: Workflow states (Draft, Review, Approved, Active, Archived)
    with approval tracking.

DMN Modeler

Description

This module provides a DMN (Decision Model and Notation) modeler integrated into Odoo, leveraging the dmn-js JavaScript library and Odoo’s OWL framework. It allows users to create, view, and edit DMN decision tables directly within Odoo records.

Key Features

  • Interactive DMN Modeling: Utilize the powerful dmn-js library for creating and editing DMN decision tables.
  • Odoo Integration: Seamlessly embed the DMN modeler into Odoo forms using a custom field widget built with OWL.
  • Decision Table Storage: Store DMN XML definitions directly within Odoo records.
  • Version History: Automatic tracking of decision table versions with change history.
  • Templates: Pre-built decision table templates for common business scenarios.
  • Export/Import: Export decision tables as XML, SVG, PNG, or PDF, and import existing DMN files.
  • State Management: Workflow states (Draft, Review, Approved, Active, Archived) with approval tracking.

Configuration

Configuration

Installation

  • Add dmn_modeler to your Odoo addons path.
  • Install the module from the Odoo Apps menu.
  • The dmn-js library (version 17.5.0) is included in the module assets.

Access Rights

  • Users need appropriate access rights to create and edit DMN diagrams.
  • Access rights are configured in the security/ir.model.access.csv file.
  • By default, all users can read, write, create, and unlink DMN diagrams.

Categories

  • Navigate to DMN > Diagram Categories to create custom categories.
  • Categories help organize decision tables by business area or purpose.
  • Use categories to filter and group related decision tables.

Templates

  • Navigate to DMN > Template Categories to organize templates.
  • Create custom templates for frequently used decision patterns.
  • Templates can be marked as public (available to all users) or private.

States and Workflow

The module supports the following states for decision tables:

  • Draft: Initial state, allows full editing of the decision table.
  • Under Review: Diagram is submitted for review, editing is restricted.
  • Approved: Diagram has been approved, ready for activation.
  • Active: Diagram is in use, editing is restricted.
  • Archived: Diagram is no longer active.

Usage

Usage

To use the DMN Modeler module, follow these steps:

Creating a Decision Table

  • Navigate to DMN > DMN Diagrams.
  • Click “New” to create a new decision table.
  • Enter a name, description, and select a category.
  • In the “DMN Modeler” tab, use the interactive editor to create your decision table.
  • Add inputs, outputs, and rules to define your decision logic.
  • Save the diagram.

Using Templates

  • Navigate to DMN > Templates.
  • Browse available decision table templates.
  • Click “Use Template” on a template to create a new diagram based on it.
  • Customize the template to fit your needs.

Managing Versions

  • Each time you modify a decision table, a version history entry is automatically created.
  • View version history in the “Version History” tab of a diagram.
  • Compare different versions to track changes over time.

Exporting Decision Tables

Use the export buttons in the DMN Modeler toolbar:

  • Export XML: Download the DMN XML definition
  • Export SVG: Download as SVG image
  • Export PNG: Download as PNG image
  • Export PDF: Download as PDF document

Importing Decision Tables

  • Click the “Import” button in the DMN Modeler toolbar (only available in draft state).
  • Select a .dmn or .xml file containing a DMN definition.
  • The decision table will be imported and displayed in the editor.
